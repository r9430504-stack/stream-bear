# Мишка для стрима

Интерактивный мишка для OBS: отвечает на вопросы из чата и реагирует на донаты.

**Twitch:** открой https://r9430504-stack.github.io/stream-bear/ , впиши свой канал, нажми «Подключить Twitch» и вставь ссылку из строки статуса в OBS как источник «Браузер».

**TikTok Live:** нужен мост на своём компьютере — `npm install`, затем `npm start -- имя_в_тиктоке` и ссылка `http://localhost:3737/?obs` в OBS.
